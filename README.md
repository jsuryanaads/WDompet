# Wdompet V1

Frontend aplikasi keuangan sederhana.

## Fitur
- Saldo, pemasukan, pengeluaran
- Tambah dan hapus transaksi
- Pencarian
- Export CSV
- Responsive
- Penyimpanan browser dengan localStorage

## Menjalankan
Buka `index.html` di browser.

## GitHub Pages
Upload seluruh file ke repository GitHub, lalu aktifkan:
Settings → Pages → Deploy from branch → `main` → `/ (root)`.

> V1 belum menggunakan database/server. Data transaksi tersimpan hanya pada browser/perangkat yang digunakan.
